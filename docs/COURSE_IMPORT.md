# 周规划表与课程表导入

## 周规划表

“计划”首次进入时默认显示今天的日列表。切换到“周规划表”后，课程和手动创建的计划会显示在周一到周日的时间网格中。七天列和全天时间轴会自动适配当前屏幕；在周表上向左滑查看下一周，向右滑查看上一周。顶部的上一周、下一周、本周和日期选择入口仍可使用；跨午夜计划按天显示。

点击计划块打开详情及原有开始、完成、删除操作。点击星期表头可进入当天日列表，也可用顶部“日列表”切换。创建计划仍使用当前选中日期。普通重复计划保留原有“完成后生成下一次”的行为，不自动补建未来整学期；导入课程则按明确周次提前生成每一次安排，完成时不再额外生成下一次。

课程块直接标出地点，并按课程名称使用主题邻近色区分。同一时间发生的多个计划采用叠放显示并标注数量，点击后先选择要查看的计划。浏览的不是当前自然周时，课程块会统一淡化，便于识别当前周。

网页读取和 Excel 导入都可以新建命名课表，也可以选择已有课表继续追加；同一来源可创建多张课表，旧版本课程仍保留在“历史导入课表”。计划页可在“仅计划”及各课表之间切换；选择某张课表时，只显示该课表的课程，并始终叠加普通计划。不同课表中的相同课程不会互相去重，同一课表重复导入仍会跳过重复记录。

课表切换条右侧的“选择和管理课表”会列出全部课表。点击课表名称即可切换，当前课表带有选中标记；“仅显示普通计划”会暂时隐藏所有课程。右侧删除按钮可删除整张课表，确认页面会显示其中的课程数量；删除后，该表课程和对应提醒会一并清理，普通计划及其他课表不受影响。整表删除不可撤销，需要保留时请先在设置中导出数据备份。

## 导入文件格式

入口：“计划”右上角“导入课表”。支持直接登录教务系统读取网页课表，也保留逐行课程明细 `.xlsx` 导入；不支持 `.xls` 或课表图片。

网页单元格支持“课程名称：… 教师：… 上课地点：…”这类同一行标签内容，也支持按“课程名、教师、周次、教室”换行排列的常见课表。对于“课程名(节次)校区教室教师选修”这类没有标签和空格的紧凑格式，也会拆分课程、地点和教师，并移除课程类型后缀。教师字段兼容任课教师、任课老师、授课教师、上课教师等名称；地点字段兼容上课地点、上课教室、教室名称和场地。导入预览中仍应逐项核对教师与地点。

| 列名 | 说明 |
| --- | --- |
| 课程名称 | 必填，最多 120 字符；保留名称中的符号 |
| 星期 | 必填，1–7 或 星期一/周一 等，7 表示星期日 |
| 开始节数 | 必填，1–24 的整数 |
| 结束节数 | 必填，不早于开始节数 |
| 老师 | 可空；兼容“教师”“任课教师” |
| 地点 | 可空；兼容“教室” |
| 周数 | 必填；兼容“周次” |

表头可以位于前 20 行内，多张有效工作表可选择。文件上限 10 MB，表最多 2000 行，单次最多生成 5000 次课程。无法识别的行会列明行号、课程名和原因，用户明确勾选后才可跳过，不会擅自补星期、节次或周数。

周次数例：

- `1-16`：第 1 至 16 周。
- `3-17单`：第 3、5、7、9、11、13、15、17 周。
- `12-18双`：第 12、14、16、18 周。
- `7-10、12、15-17`：第 7、8、9、10、12、15、16、17 周。

## 导入步骤

1. 直接读取：展开“从教务系统直接读取”，输入学校教务系统网址，在应用内网页中自行登录并进入“我的课表”或“课表查询”。完整课表显示后点击“读取当前课表”。应用使用页面中首张可识别的有效课表；登录表单由教务网页处理，Learning Bird 不保存账号和密码，只有用户点击读取时才提取当前页面内可见的表格文字。
2. Excel 备用方式：也可在系统浏览器导出课程明细 Excel，返回后点击“选择课表文件”。应用不会修改原文件。网页使用图片、跨域页面或特殊课表控件而无法识别时，可继续使用 Excel 导入。
3. 在“保存到哪张课表”中选择“新建课表”并填写名称，或选择已有课表继续追加。选择目标后才生成预览，去重和冲突都只针对该课表及普通计划计算。
4. 指定学期第一周的星期一。文件中的学年名称不能替代这个日期，不会自动推断开学日。
5. 展开节次时间并逐项核对上下课时间，必要时修改；初始时间是示例，不代表学校作息。必须勾选确认。连续多节课以第一节上课到最后一节下课作为计划时段，包含中间课间。
6. 核查未排课记录；补充原表后重新选择，或明确勾选本次跳过。
7. 生成预览，分别查看读取到的课程信息数量、按周次展开后的实际安排数量、重复次数及全部具体日期。时间重叠的课程会自动保留，并在周表同一时间格叠放显示。
8. 点击“确认导入课程”。之后返回周规划表查看首个有课的星期。

导入的课程分类为“课程”，保留教师、地点、周次和节次，并默认创建开始前 10 分钟的提醒。应用在前台时弹窗会显示课程名称、开始时间和地点；后台或锁屏时使用系统通知。不会自动调整法定节假日、调休、补课或停课；学校另有安排时需在计划中处理。

## 重复、冲突与备份

- 根据课程名、教师、地点、具体日期和时间识别已导入课程；同表重复行、反复导入或并发提交不重复建课。
- 不覆盖已完成状态，不自动恢复已删除的课程。去重标记随原有 JSON 备份保存。
- 修改时间或教师/地点后再导入视为不同安排，可能新增课程；请核对冲突预览，原有课程不会被自动替换。
- 课程与普通计划时间重叠时会提示数量，可确认后并列保留；不会覆盖或删除已有计划。
- 整批入库使用事务，失败不留下半张课表；没有数据库结构升级。

## 所附样例核查

实际课表示例中，14 条可排课课程信息按原有周次展开为 144 次实际上课安排；这不是 144 门课程，也不是旧课表残留。示例里一条课程记录缺少星期和节数，会被列为待补充记录，不自动导入。

样例没有学期第一周日期及实际节次时间，需在导入时由用户确认。自动化测试用指定日期及示例时间检查日期计算，并不表示已确定学校开学日期或作息。
