# 工具箱阶段交付：考研资料文件夹

## 已完成

- 新增第五个底部入口“工具箱”。
- 工具箱内提供“考研资料”本地资料库。
- 通过系统选择器直接选择文件夹，视频、文本和其他文件会一并复制，并保留子文件夹层级。
- 同一文件夹重复导入时自动编号，不覆盖已有资料，也不修改原文件夹。
- 列表显示文件名称、相对路径、大小和类型，并支持确认删除应用内副本。
- 内置播放器支持播放/暂停、进度拖动及前后 10 秒跳转。
- TXT、Markdown、CSV、日志和字幕文件可在应用内阅读和选择文字，其他格式暂只负责安全保存。
- Android 和 iOS 使用同一套资料管理逻辑。

## 数据说明

- 资料保存在应用私有文档目录，不需要宽泛存储权限。
- 删除资料仅删除应用内副本，不影响用户选择的原资料。
- 现有 JSON 备份不包含资料文件，卸载应用会清除应用私有目录。

## 验证结果

- Flutter 静态分析：通过，无问题。
- 自动化测试：119 项通过；1 项需要用户原始课表路径的可选测试按设计跳过。
- 新增覆盖：文件夹递归复制、层级保留、重名文件夹、类型识别、文本阅读、删除隔离、资料页面和第五个导航入口。
