# Learning Bird 使用说明

适用版本：1.0.0-rc.3（10），Android 8.0 及以上。当前为候选测试版，公开分发前仍需使用正式签名并完成最终真机验收。

## 首次使用
打开“单词”，选择预置词书，或自己创建词书再导入词汇；在“计划”中安排任务；在“番茄钟”开始专注。“今日”汇总各模块数据，首页右上角可进入设置。

首次进入“计划”默认打开“日列表”并定位今天，直接显示今日计划。切换到“周规划表”后，周一到周日以及全天时间轴会自动压缩到一个屏幕内；点击课程块查看完整时间、地点和操作，点击星期表头可进入当天日列表。

## 选择预置词书（当前源码新增）

进入“单词 → 预置词书”，选择考研英语（4,801 词）、大学英语四级（3,849 词）或大学英语六级（5,805 词，含四级基础词），点击“添加 / 打开词书”后即可查看全部单词和开始学习。无需联网或导入 Excel。重复添加直接打开原书，不重置进度；已有自定义释义会保留。预置词书也可删除，删除后重新添加不恢复旧进度。

词库来自 ECDICT 开源参考数据，不是官方完整大纲；来源与 MIT 许可可在选择页面查看。详情见 [预置词书说明](BUILTIN_WORD_BOOKS.md)。新增资源需在 Android Studio 停止后重新 Run，历史发布包不自动获得这些资源。

## 导入词汇
1. 使用同目录 templates/word-import-template.xlsx：只有一张表、两列“单词”和“意思”。
2. 保留第一行表头，从第二行起一行一个词。两行示例可删除或替换。
3. 两列都要填写，不需要音标、例句等其他内容；也支持英文表头 word、meaning 和旧表头“释义”。只支持 .xlsx 或 UTF-8 CSV，不支持 .xls、重复表头和合并单元格。公式请先粘贴为值。
4. 在“单词 → 导入单词”选择目标词书和文件，检查字段映射与前五行预览，确认后导入。
5. 同一文件可反复导入，每次建立独立批次。缺少单词或释义的行会被跳过。
6. “跳过词书内重复项”保留原内容；“用新内容覆盖”会修改公共单词内容，可能同时影响其他引用该词的词书，请谨慎选择。

## 查看整本词书
在“单词”页面点击词书名称或卡片空白区域，进入全部单词列表，按字母顺序查看单词和意思。这里显示整本词书，不只显示当天学习或待复习的词；向下滚动可继续查看。页面中可点击“添加单词”，新增后列表自动刷新；右上角可开始学习。卡片上的删除和添加按钮仍执行各自操作，不会误进入列表。

## 手动添加一个单词
在“单词”找到目标词书，点击卡片上的“添加单词”，填写“单词”和“意思”后点击“添加”。成功后词数自动更新，可直接开始学习；点击“取消”不会保存。
手动添加会实时检查格式：英文单词最长 80 字符，只允许字母以及词内连字符/撇号（如 well-known、can't）；意思最长 500 字符，需包含中文释义，可带词性、标点和换行，拒绝乱码及不可见控制字符。错误会显示在输入框下方并阻止保存。此检查不是词典校对，不能判断单词是否真实存在或翻译是否准确。Excel/CSV 批量导入规则不因这次手动添加校验而改变。
同一本词书中的重复词（忽略大小写和首尾空格）不会再次添加，也不会重置学习进度。若其他词书已收录相同单词，需使用已存的意思才能添加，避免静默改动其他词书；冲突时会显示已有意思并保留输入。

## 背词和删除词书

### 每本词书的每日目标（当前源码新增）

点击单词本进入详情，在“每日目标”右侧点击“设置”，填写每天学习词数（1–1000，默认 20）。只修改当前词书，例如考研每日 30 词、四级每日 20 词，目标和完成数互不影响。

新学与到期复习合计；完成一个词才计为 1 词，同一本书同一天的同一词不会重复计数。新词的前两次“认识”不计为完成，第三次通过才计入。到期复习优先，目标不是对新词与复习分别限额。

当天重新进入会扣除已通过词数；达到目标时提示完成，仍可点“继续学习”。每次加练最多取当前目标词数，可反复加练，直到没有新词或到期复习词，不会提前抽取未到期的已学词。加练也累计到今日完成数，可以超过目标。

按手机本地日期在午夜重新统计，历史记录与未完成的认识次数不清空。设置和进度随备份保存；提高目标可以补学，降低目标不删除已学记录；删除词书同时删除其专属目标设置。若学习中途跨天，当前轮次继续保留，完成记录按实际通过时间所属日期计数。

### 学习与复习

有单词的词书可点击“开始学习”。先回忆，再查看释义，仅需选择“认识”或“不认识”。

已经熟悉的词可点击“跳过（已认识）”，不必先看释义：直接通过当前词并进入下一个，计入该词书的今日完成数，不再等待三次确认。这不是临时略过或永久移除；首次跳过后从 3 天后安排复习，之后沿用认识的复习间隔。后续选择“不认识”仍会重置为三次确认。保存失败会保留原卡片，可重试。

- 新词需要对同一单词连续选择 3 次“认识”才通过。前两次会重新排到本轮队尾，再次出现时答案恢复隐藏；界面不显示单词的认识次数或确认阶段提示。
- 已通过的词，后续到期复习只需 1 次“认识”即可通过。
- 任意阶段选择“不认识”，该词的确认次数清零，回到本轮队尾，重新需要连续 3 次“认识”。过程中再次不认识也会清零。
- 前两次确认不会延长跨天复习间隔；首次或遗忘后完成三次确认，从 3 天后开始安排复习，后续通过时逐步延长。
- 本轮通过数按单词计算，不按点击次数计算。中途退出会保存每个词的确认进度；不同词书中同一个词的进度独立。备份与恢复包含这些进度。
- 旧版已进入复习或掌握的词保持后续一次确认模式；旧版最后反馈为不认识的词在下次学习时进入三次确认。历史记录不清空。

当前源码已移除词卡的声音按钮和朗读调用；保留单词、音标、释义及学习反馈操作。
词书卡片的垃圾桶按钮会弹出确认框；确认后永久删除该词书的关联、进度、复习和导入记录。其他词书不受删除影响；关联计划保留，但解除词书关联。请先备份重要进度。

### 单词测试（当前源码新增）

在“单词”首页点击“单词测试”，先选择一本有内容的词书，再选择测试方式。每轮随机抽取最多 20 个单词：

- 看词选义：查看英文单词，从释义选项中选择答案。
- 看义回忆单词：查看中文释义，先在心中回忆，显示单词后选择“想起来了”或“没想起”。
- 单词拼写：根据释义输入完整英文单词；忽略大小写及首尾空格，空输入会提示填写，不会直接记错。

测试是独立练习，不占该词书每日目标。答对只计入本轮测试结果，不会让尚未到期的复习提前完成；答错会按“不认识”保存并自动进入错词本，之后需要通过错词强化重新连续认识三次。每轮结束显示答对数量，可以返回更换词书或测试方式。

### 错词本与强化（当前源码新增）

“单词”首页顶部的“错词本”会自动收录学习时选择过“不认识”、且尚未重新通过的单词。进入后可以查看单词、意思、来源词书和累计遗忘次数，不需要手动添加或整理。

点击“开始强化”后使用与普通词卡相同的“认识 / 不认识 / 跳过（已认识）”操作。错词需要连续三次选择“认识”才会自动从错词本移出；强化中再次选择“不认识”会清零并重新需要三次。“跳过（已认识）”表示已经确认掌握，会直接完成该词的强化。

错词强化单独进行，不受某一本词书的每日目标限制，也不会修改每日目标。错词仍属于原词书：同一个单词在不同词书中的学习进度相互独立，删除原词书后对应错词也会移除。错词本由现有学习记录自动生成，因此会随正常备份和恢复一起保留。

## 计划与番茄钟

“计划”首次打开时显示今天的日列表。切换到课程表式周规划后，可按星期和时间查看课程及学习任务；左右滑动切换前后周、点击“本周”返回当前周，点击计划块查看详情。

右上角“导入课表”支持逐行课程明细 Excel。选择文件后必须设置学期第一周的周一，并核对每节课的上下课时间；支持单双周和分段周次。先预览，再确认保存，缺少排课信息的行和时间冲突均会提示。详见 [周规划表与课表导入](COURSE_IMPORT.md)。

创建计划时填写标题、时间和提醒，按需设置重复规则、分类或关联词书。重复规则可以直接选择“不重复、每天、每周、每月”；再次点击已选中的重复规则即可取消并恢复“不重复”。计划保存后仍可从日列表右侧菜单或周表详情选择“取消每天/每周/每月重复”，当前日期的计划和提醒会保留，但以后完成时不再按原规则自动生成。到达提醒时间且应用正在前台时会弹出“计划提醒”；从课表导入的课程默认提前 10 分钟提醒，并在弹窗中显示地点。升级前已导入且尚未结束的课程会自动补上提醒，不需要重导课表。应用在后台或锁屏时使用系统通知。
番茄钟支持专注、短休息和长休息，可暂停、继续、提前结束或放弃；关联计划的有效专注时长会计入计划实际用时。

专注时间结束时，应用前台会弹出“专注时间结束”，可选择稍后休息或直接开始短/长休息。休息结束时会弹出“休息时间结束”，可选择稍后开始或直接开始下一轮专注。应用会在到时瞬间判断前后台状态：前台使用应用弹窗；后台、其他软件或手机桌面状态不会取消已安排的系统通知，而是显示系统顶部横幅，并启用声音和振动；锁屏时显示锁屏通知。Android 13 及以上使用计时器专用的精确闹钟权限，Android 12/12L 首次启动时申请“闹钟和提醒”权限；无法精确定时时会安全降级为可能延迟的普通提醒。更新后请在系统的应用通知设置中确认“番茄钟到时弹窗”通道允许悬浮/横幅通知。

OPPO/一加/realme 的 ColorOS 还需进入“设置 → 应用 → 应用管理 → Learning Bird → 耗电管理”，选择“完全允许后台行为”，不要保留“智能优化后台运行”；同时允许锁屏通知。否则 ColorOS 可能在计时启动时显示精确时间，却在到点后把闹钟延后。其他带厂商省电管理的手机也应将 Learning Bird 设为不限制后台活动。

## 工具箱与考研资料文件夹

底部进入“工具箱 → 考研资料”，点击“导入文件夹”后通过手机系统目录选择器选中一个资料文件夹。应用会递归复制其中的视频、文本及其他文件，并保留原有子文件夹层级；原文件不会被移动或删除。同一文件夹再次导入会自动增加序号并保留两份。

点击 MP4、MOV、M4V 或 WebM 视频可在应用内播放，支持播放、暂停、拖动进度、前进 10 秒和后退 10 秒。点击 TXT、Markdown、CSV、LOG 或 SRT 文本可在应用内阅读和复制。PDF、Word、压缩包等其他文件会保存并显示在列表中，当前版本暂不在应用内预览。不同手机支持的视频编码可能不同，兼容性最好的是 H.264 视频编码与 AAC 音频编码的 MP4 文件。

列表中的垃圾桶只删除应用内保存的文件副本，不删除原资料。资料文件可能占用大量空间，请留意手机剩余容量。JSON 数据备份不包含资料文件，卸载应用会删除应用内副本，因此应始终保留原文件夹或另行备份。

## 通知
在“设置 → 系统通知”允许通知。进入“设置 → 后台提醒设置检查”可集中查看通知、精确闹钟和 Android 电池优化状态，并一键跳转到对应系统页面；从系统设置返回后会自动重新检查。应用打开在前台时，每 15 秒检查一次到时提醒并弹窗；番茄钟在后台或锁屏时使用系统闹钟级精确定时通知。计划和课程提醒仍允许系统按省电策略合并，可能出现延迟。

各厂商的后台开关没有标准 Android 读取接口，因此所有 Android 手机上检查页都会保留人工确认提示。点击“打开应用设置”，再进入“耗电管理”“电池”或“后台活动”，把 Learning Bird 设为“不限制”“允许后台活动”或同等选项；如果系统提供“自启动”，也应允许。设备重启与不同厂商系统仍需真机验收；不要把应用提醒作为关键事务的唯一提醒。

## 备份与迁移
“设置 → 备份全部数据”导出 JSON；在另一台设备通过“从备份恢复”导入。恢复会覆盖当前全部数据，建议先备份当前内容。
备份未加密，不主动上传网络；若选择了第三方云盘保存位置，其同步行为由该服务决定。校验值用于发现文件损坏，不构成加密或身份认证。卸载应用会丢失应用内数据，务必先导出备份。

## 更新安装
同应用标识、同签名的新版本可覆盖安装；测试版改为正式签名后无法直接覆盖。先导出备份，确认正式版安装方案后再迁移；不要直接卸载唯一的数据副本。

## 常见问题
- “Connection terminated during handshake / Failed to update packages”：这是电脑构建时依赖服务器连接失败，不是 USB 本身故障。依赖已备妥时可用 flutter run --no-pub 调试。
- Excel 无法读取：使用本模板保存为 .xlsx；确认第一张表第一行是非空、唯一表头，至少有一行有效数据。
- CSV 乱码：另存为 UTF-8 CSV。
- 旧中文缓存构建失败：本机使用 D:/PubCache，并重启 Android Studio 使环境变量生效。
