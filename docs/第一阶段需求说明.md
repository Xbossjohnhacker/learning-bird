# learning bird 第一阶段需求说明

> 阶段：第 1 周「需求与原型」  
> 状态：范围已冻结，可进入第 2 周基础建设  
> 依据：`learning bird_项目开发计划书.docx`

## 1. 阶段目标

第一阶段的目标不是开发正式功能，而是消除进入工程建设前的关键歧义：确定 V1.0 范围、核心用户流程、信息架构、数据边界与页面原型。完成本阶段后，开发人员应能在不重新讨论产品方向的情况下开始搭建 Flutter 工程、路由、主题和数据库。

## 2. 产品定义

learning bird 是一款以“计划—执行—复习”为闭环、完全离线运行的考研学习管理工具。首发平台为 Android 8.0 及以上，后续再适配 iOS。

### 2.1 核心价值

1. 用一个应用连接背词、任务计划与专注计时，减少工具切换。
2. 打开应用即可知道今天要做什么，并能立即开始。
3. 核心数据默认只保存在本机，无网络也能完成主要流程。
4. 学习结果可长期追踪，并能完整备份和恢复。

### 2.2 目标用户

- 主要用户：需要长期背词、安排阶段任务并记录专注时间的考研学生。
- 次要用户：备考四、六级或其他英语考试的学生。
- 扩展用户：希望统一管理任务与专注时间、重视隐私和离线能力的大学生。

## 3. V1.0 范围冻结

### 3.1 必须包含

| 模块 | V1.0 能力 |
| --- | --- |
| 今日 | 今日计划进度、最近待执行计划、待学/待复习单词、番茄数量、专注时长、快捷入口 |
| 单词 | Excel/CSV/内置词书/手动导入，词书管理，新词学习，四级反馈，简化间隔复习，学习记录 |
| 计划 | 一次性与重复计划，优先级、分类、提醒、状态流转，完成后安排下一次 |
| 番茄钟 | 自定义专注/休息时长，开始、暂停、继续、结束、放弃，关联计划，后台时间校准 |
| 统计 | 日/周/月专注统计，计划完成率，新学/复习/掌握单词统计 |
| 设置 | 主题、通知权限、计时规则、学习目标、完整备份与恢复 |

### 3.2 明确不包含

- 登录、账号体系、云同步和多设备实时同步。
- 社区、排行榜、好友、打卡分享。
- 在线词典、在线发音资源和必须联网的 AI 功能。
- 桌面端、网页端与 Apple Watch 等可穿戴端。
- 复杂自适应算法；V1.0 使用可解释的简化间隔规则。
- 完整日历、多维数据报表和高级词书编辑，延后到 V1.1。

## 4. 信息架构

底部导航固定为四个一级入口：

1. 今日：每日总览与跨模块快捷操作。
2. 单词：词书、导入、学习与复习。
3. 计划：任务列表、创建、详情、重复规则与提醒。
4. 番茄钟：专注计时、关联任务与历史记录。

设置从“今日”页右上角进入。二级页面使用返回导航，不新增第五个底部入口。

## 5. 核心用户故事与验收条件

### US-01 查看今日总览

作为备考学生，我希望打开应用后立刻看到今天的关键任务，以便无需整理就能开始学习。

验收条件：

- 显示计划完成数与总数，且数据来自当天计划。
- 显示待学习、待复习和已完成单词数。
- 显示当天完成的番茄数与累计专注时长。
- 最近一项待执行计划可一键开始专注。
- “开始背词”“创建计划”“开始专注”均不超过一次点击可达。

### US-02 导入单词

作为用户，我希望从 Excel 或 CSV 导入已有单词，以便快速建立个人词书。

验收条件：

- 导入步骤为：选择文件—映射字段—预览—重复处理—确认。
- 单词导入可以重复执行；同一词书允许连续追加多个文件，也允许再次选择曾导入过的文件。
- 每次导入都是独立批次，完成页提供“继续导入”，无需退出后重新进入。
- 再次导入相同内容时仍须执行重复检测，不能静默生成同一词书内的重复条目。
- 每个批次分别保存来源文件、成功数、跳过数和错误行，并可在词书中查看历史记录。
- `word` 和 `meaning` 缺失时必须阻止导入并说明原因。
- 支持跳过、覆盖或保留重复单词。
- 大量导入展示进度；失败时不留下半份数据。
- 生成包含成功数、跳过数和错误行的导入结果。

### US-03 学习与复习单词

作为用户，我希望根据自己的记忆反馈获得下一次复习安排，以便持续巩固。

验收条件：

- 卡片正面显示单词和音标，背面显示释义、例句、短语和笔记。
- 用户可选择“忘记、模糊、记得、熟练”。
- 忘记：当天稍后；模糊：1 天后；记得：3 天后；熟练：7 天后。
- 每次反馈同时保存复习记录并更新下一次复习时间。
- 当天任务完成后展示学习结果，而不是直接回到空白列表。

### US-04 创建和完成计划

作为用户，我希望创建一次性或重复计划，并在完成后快速安排下一次，以保持学习连续性。

验收条件：

- 标题、开始日期时间为必填项。
- 支持不重复、每天、每周指定日期、每月和自定义间隔。
- 状态至少包含未开始、进行中、已完成、已逾期、已跳过。
- 完成计划后提供结束、复制到明天、指定下一次时间和创建关联任务。
- 创建计划的主要流程不超过三个步骤。

### US-05 接收本地提醒

作为用户，我希望计划到点时收到通知，以免错过学习安排。

验收条件：

- 支持到点及提前 5/10/30 分钟提醒。
- 通知可执行“立即开始”“延后 10 分钟”“标记完成”。
- 应用启动和设备重启后会校验并恢复未触发提醒。
- 拒绝通知权限时，应用说明影响并保留应用内计划功能。

### US-06 使用番茄钟

作为用户，我希望为某项计划启动番茄钟，并在切换到后台后仍获得准确的剩余时间。

验收条件：

- 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟，每 4 个番茄进入长休息。
- 支持开始、暂停、继续、提前结束和放弃。
- 可关联计划；完成记录自动累计到计划实际用时。
- 后台恢复时按时间戳重新计算，不依赖常驻倒计时。
- 系统时间异常时给出校准处理，不能产生负时长。

### US-07 备份与恢复

作为用户，我希望完整导出并恢复本地数据，以便换机或故障后不丢失学习记录。

验收条件：

- 备份包含数据库、设置和必要的版本信息。
- 恢复前创建当前数据快照并二次确认。
- 不兼容版本必须停止恢复并说明原因。
- 恢复成功后重新校验通知与进行中的计时状态。

## 6. 关键业务规则

### 6.1 计划状态

`未开始 → 进行中 → 已完成` 是正常路径；开始时间已过且未完成时可标记为 `已逾期`；用户主动放弃本次执行时为 `已跳过`。已完成与已跳过记录保留，不做物理删除。

### 6.2 重复计划

重复规则是计划模板的一部分。每次实例完成后再生成下一实例，避免一次性预生成无限记录。生成操作必须幂等，使用模板与计划日期的唯一约束防止重复。

### 6.3 番茄计时

持久化开始时间、目标结束时间、暂停开始时间和累计暂停时长。界面上的每秒倒计时仅用于显示，最终结果始终由持久化时间戳计算。

### 6.4 单词复习

复习状态属于“单词—词书”关系，而不是单词本身。同一个单词加入不同词书后可拥有独立进度。

## 7. 非功能要求

- 离线：今日、单词、计划、番茄钟、历史和通知核心流程无需网络。
- 性能：普通页面 1 秒内可交互；支持至少 10 万条单词；列表必须分页或虚拟化。
- 可靠性：数据库迁移、批量导入和恢复均使用事务；应用异常退出后可恢复计时状态。
- 隐私：默认不上传数据；导出和删除操作明确说明影响范围。
- 兼容性：第一版重点支持 Android 8.0 及以上。
- 易用性：高频操作三步内完成；颜色不是状态的唯一表达方式。
- 可访问性：触控目标不小于 48dp；正文支持系统字体缩放；关键按钮有语义标签。
