# Learning Bird 商店发布资料

## 基本信息

- 应用名称：Learning Bird
- 目标版本：1.0.0（建议构建号 19）
- 分类：教育 / 效率
- 支持系统：Android 8.0 及以上
- 应用标识：`com.learningbird.learning_bird`（首次公开发布前必须最终确认，发布后不应更改）

## 一句话简介

离线管理考研计划、单词复习、课表和番茄专注。

## 完整介绍

Learning Bird 把计划、执行和复习放在一个完全离线的学习空间中。你可以使用周规划表和日列表安排任务，导入课程表，设置计划与番茄钟提醒；也可以创建词书、导入两列表格、使用预置考研及四六级参考词书，并按复习节奏完成单词学习。

考研资料工具箱支持导入整个文件夹，在应用中播放常见视频或阅读文本。计划还可以关联手机上的学习、运动等应用，在日列表点击图标直接打开。学习数据默认保存在设备本地，不需要账号，也不包含广告和分析服务。

## 发布素材

- 512 × 512 PNG 应用图标：`release-assets/learning-bird-store-icon-512.png`
- 至少 4 张真实手机截图：首页、日/周计划、单词学习、番茄钟或资料工具箱
- 推荐 1080 × 1920 或更高的竖屏截图，不显示个人课表、姓名、文件路径或通知内容
- 隐私政策公开 HTTPS 地址
- 支持邮箱与发布者名称

## 权限审核说明

通知、精确闹钟和开机完成仅用于用户设置的计划及番茄钟提醒。文件由系统选择器在用户主动操作时授予。关联应用功能只查询带桌面入口的可启动应用，并将用户所选应用名称与包名保存在本地。

Play Console 需单独完成 `USE_EXACT_ALARM` 与 `USE_FULL_SCREEN_INTENT` 申报。精确闹钟用于用户主动设置的计划日历提醒和番茄计时器；全屏意图仅作为用户授权后的闹钟式强提醒，未授权时降级为普通系统通知。
