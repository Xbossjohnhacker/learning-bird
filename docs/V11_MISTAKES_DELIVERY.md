# V1.1 第一段交付：错词本与错词强化

## 已完成

- 单词首页提供错词本入口和待强化数量。
- 选择“不认识”后自动收录，列表展示释义、来源词书和遗忘次数。
- 提供独立错词强化词卡，不占用单本词书每日目标。
- 连续三次认识后自动移出，再次不认识会重新开始三次确认。
- 支持“跳过（已认识）”直接确认掌握。
- 删除词书、备份和恢复继续沿用现有数据关联，无数据库升级。

## 验证结果

- Flutter 静态分析：通过，无问题。
- 自动化测试：99 项通过；1 项需要用户原始课表路径的可选测试按设计跳过。
- 新增覆盖：自动收录、来源显示、强化入口、三次认识后移出。

## 真机查看

在 Android Studio 停止当前运行后重新 Run，进入“单词”。任意学习词卡选择一次“不认识”，返回单词首页即可看到错词本数量；进入错词本后点击“开始强化”。仅热重载通常也能看到界面变化，但完整重新运行更稳妥。
