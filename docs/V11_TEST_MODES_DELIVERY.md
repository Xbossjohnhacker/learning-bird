# V1.1 第二段交付：三种单词测试模式

## 已完成

- 单词首页新增测试中心入口和词书选择。
- 看词选义：英文题干与释义选项。
- 看义回忆单词：释义题干、显示答案、自我确认。
- 单词拼写：完整输入校验，忽略大小写和首尾空格。
- 每轮随机抽取最多 20 词并显示答题进度及最终成绩。
- 答错自动进入错词本；答对不提前推进复习计划。
- 测试不占单本词书每日学习目标。

## 验证结果

- Flutter 静态分析：通过，无问题。
- 自动化测试：104 项通过；1 项需要用户原始课表路径的可选测试按设计跳过。
- 新增覆盖：测试队列、三模式入口、选择题错题收录、回忆答对不改复习、拼写空输入与大小写处理。

## 真机查看

在 Android Studio 停止当前运行后重新 Run，进入“单词 → 单词测试”，选择词书和测试方式即可。若在测试中答错，返回“错词本”可看到该词。
