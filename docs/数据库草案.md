# learning bird 数据库草案 v0.1

## 1. 设计目标

- SQLite 单机数据库，所有核心功能完全离线。
- Drift 负责类型安全查询、Schema 版本与迁移。
- 时间统一保存为 UTC 毫秒时间戳，界面按设备时区显示。
- 业务记录优先软删除；导入、迁移与恢复必须使用事务。
- Schema 从版本 `1` 开始，任何变更都必须追加迁移测试。

## 2. 实体关系摘要

```text
word_books 1 ── n word_book_items n ── 1 words
word_book_items 1 ── 1 review_schedules
word_book_items 1 ── n review_records

categories 1 ── n plans
plans 1 ── n reminders
plans 1 ── n pomodoro_sessions
plans n ── 0..1 word_books

import_records 1 ── n import_errors
app_settings：键值配置
```

### 3.10 import_records 与 import_errors

`import_records` 保存文件名、类型、目标词书、开始/结束时间、总行数、成功数、跳过数、失败数和状态。`import_errors` 保存导入记录 ID、源行号、错误码、错误说明和原始数据摘要。导入成功前所有写入处于同一事务中。

重复导入规则：

- 每次点击导入都创建新的 import_records，历史批次互不覆盖。
- 文件指纹只用于提示“此文件曾导入”，不设唯一约束，因此同一文件可以再次导入。
- 同一词书仍由 uq_book_word(word_book_id, word_id) 保证不会出现重复条目。
- 对已存在单词执行用户选择的“跳过”或“覆盖内容”策略；也可以改为导入到另一词书。
- 单个批次失败只回滚当前批次，不影响此前成功批次。

### 3.11 app_settings

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| key | TEXT | PK | 设置键 |
| value | TEXT | NOT NULL | JSON 或标量字符串 |

首批键：`theme_mode`、`daily_word_goal`、`focus_minutes`、`short_break_minutes`、`long_break_minutes`、`long_break_interval`、`notification_enabled`、`backup_schema_version`。

## 4. 删除与外键策略

- 开启 `PRAGMA foreign_keys = ON`。
- 词书软删除，不级联删除全局 `words`；清理孤立单词使用独立维护任务。
- `review_schedules` 和 `review_records` 随 `word_book_items` 级联删除。
- 删除计划时保留已发生的 `pomodoro_sessions`，将 `plan_id` 设为 NULL。
- `reminders` 随计划删除或取消，平台通知 ID 同步注销。

## 5. 迁移与备份原则

1. 每次 Schema 变化递增版本号并提供从上一版本升级的迁移。
2. 升级前建立数据库文件快照；迁移全部在事务中执行。
3. 备份清单包含 `schemaVersion`、应用版本、创建时间、数据库校验值。
4. 恢复前校验格式、版本和校验值，恢复后执行外键检查。
5. 数据库测试至少覆盖空库创建、逐版本升级、失败回滚和 10 万词查询。
