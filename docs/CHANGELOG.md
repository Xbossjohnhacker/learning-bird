# 版本记录

## 1.0.0+19 — 2026-09-13（正式发布准备）

- 完成首次 GitHub 正式发布，正式 APK 使用项目所有者的独立密钥签名。
- 支持教务系统将课程名、节次、校区教室、教师和课程类型紧密拼接且没有标签或换行的格式。
- 实测格式“机器学习★(5-6节)东校区博学楼222喻莎选修”可拆为课程“机器学习★”、地点“东校区博学楼222”、教师“喻莎”。
- 自动移除必修、选修、限选、考查、考试等课程属性后缀，避免混入教师姓名。

## 1.0.0+18 — 2026-09-13（正式发布准备）

- 教务系统读取只使用当前页面首张有效课表，不再显示容易混淆的 Excel 工作表选择。
- 预览区分“课程信息数量”和“按周次展开的上课安排数量”；14 条课程信息展开为 144 次安排不再表述为 144 门课程。
- 课程时间重叠自动保留并在周表叠放显示，不再因未勾选冲突确认而阻止新建课表。
- Excel 导入的字段名称改为“Excel页签（工作表）”。

## 1.0.0+17 — 2026-09-13（正式发布准备）

- 番茄钟的计划关联改为“关联课程或计划”，普通计划始终可选，课程只取计划页当前使用的课表。
- 切换课表后关联候选同步刷新；选择“仅计划”时不显示课表课程。
- 候选项增加“课程/计划”类型标识，已选课程不属于当前课表时自动取消关联。

## 1.0.0+16 — 2026-09-11（正式发布准备）

- 修复教务系统课表单元格中的课程名、教师和教室地点无法正确分割的问题。
- 支持同一行连续标签、无标签换行内容，以及“授课教师”“上课教师”“上课教室”“场地”等常见字段名。
- Excel 导入同步扩充常见教务系统表头别名。

## 1.0.0+15 — 2026-09-11（正式发布准备）

- “管理课表”升级为“选择和管理课表”，点击课表名称即可切换当前课表。
- 当前课表显示选中标记，并提供“仅显示普通计划”选项；删除操作仍由独立按钮触发。

## 1.0.0+14 — 2026-09-11（正式发布准备）

- 计划页新增“管理课表”入口，可逐张删除不再使用的课表。
- 删除前显示课表名称和课程数量并要求二次确认；删除后同步清理该表课程、数据库提醒和系统通知。
- 删除课表不会影响普通计划或其他课表；删除当前课表后自动切换到剩余课表或“仅计划”。

## 1.0.0+13 — 2026-09-11（正式发布准备）

- 课程导入支持创建任意多张命名课表，也可选择已有课表继续追加课程。
- 每张课表独立保存并独立去重；多个教务系统课表或多个 Excel 课表可同时存在并分别切换。
- 保留 1.0.0+12 已有课表和旧去重记录，无需再次迁移数据库。

## 1.0.0+12 — 2026-09-11（正式发布准备）

- 教务系统网页导入与 Excel 导入分别保存为独立课表，跨来源课程不再相互去重或混在同一视图。
- 计划页可在“仅计划”“计划 + 教务系统课表”“计划 + Excel课表”之间切换，普通计划始终与当前课表叠加显示。
- 同一来源重复导入仍会去重；旧版已导入课程自动迁移到“历史导入课表”。
- 备份格式升级到数据库 Schema 3，并兼容恢复旧版 Schema 1/2 备份。

## 1.0.0+11 — 2026-09-09（正式发布准备）

- 合并候选测试阶段后的计划、课程表、单词学习、番茄钟、资料工具箱和后台提醒改进。

- 移除已停止维护且不再需要的 `sqlite3_flutter_libs` 过渡依赖，继续由 Drift 与 sqlite3 提供本地数据库能力。
- 正式公开包仍须使用发布者自有密钥签名，并完成真机提醒、升级和数据保留验收。

## 未发布 — 番茄钟阶段结束弹窗

- 设置页新增“后台提醒设置检查”，集中展示通知、精确闹钟和 Android 电池优化状态；修改系统设置返回后自动刷新。
- 检查页可一键打开通知设置、精确闹钟授权页和当前应用详情；所有 Android 品牌统一提示检查耗电管理、后台活动和自启动。
- 厂商后台开关没有标准读取接口，页面统一标记为需人工确认，不会错误声称已自动开启。
- Android 13 及以上改用计时器应用专用的 `USE_EXACT_ALARM` 权限；Android 12/12L 保留用户授权的 `SCHEDULE_EXACT_ALARM`，避免同时声明两种权限。
- 番茄钟后台提醒改用系统 `AlarmClock` 级精确定时，修复部分 OPPO/ColorOS 设备将普通精确闹钟静默改为约两分钟浮动窗口的问题。
- 真机验证发现 ColorOS 的“智能优化后台运行”会在到点时把精确闹钟延后；使用指南已补充将 learning bird 设为“完全允许后台行为”的必要步骤。
- OPPO 真机最终验证：应用在桌面后台时，3 分钟短休息提醒按目标时间发布，系统通知记录为最高重要级别、可横幅、带声音与振动。
- 修复应用退到后台但 Dart 计时器仍运行时提前取消系统定时通知的问题；现在只有前台结束才取消系统通知并显示应用内弹窗，后台和桌面状态会保留系统横幅提醒。
- 番茄钟启动时检查并申请 Android“闹钟和提醒”精确定时权限；授权后使用允许待机的精确系统闹钟，未授权时自动降级为非精确定时，不再静默失败。
- 专注时间结束时在应用前台弹窗提示，并可直接开始短休息或长休息。
- 短休息和长休息结束时弹窗提示，可直接开始下一轮专注。
- 后台和锁屏继续使用系统通知；前台自然结束时取消对应定时通知并改用弹窗，避免重复提醒。
- Android 后台通知升级为新的最高重要级别“番茄钟到时弹窗”通道，启用顶部横幅、声音、振动和锁屏显示；iOS 使用立即横幅与声音提醒。最终展示仍受手机的通知、悬浮通知、勿扰和省电设置控制。
- 验证：119 项自动化测试通过，另有 1 项个人课表样本测试按设计跳过；静态分析与 Android Debug 构建通过。

## 未发布 — V1.1 三种单词测试模式

- 单词首页新增“单词测试”入口，可选择任意有内容的词书。
- 补齐计划书中的看词选义、看义回忆单词和单词拼写，与已完成的错词强化共同组成四种测试方式。

- 空拼写不会误判；保存错题失败时保留当前题目并允许重试。
- 验证：104 项自动化测试全部通过，另有 1 项需用户课表文件的可选测试跳过；静态分析无问题。

## 未打包 — 三次认识通过规则
- 新词需连续三次认识才通过；通过后的到期复习一次认识即可通过，任意一次不认识则清零并重新需要三次。
- 尚未通过的词在本轮队尾重新出现，显示确认进度；全部词通过才结束本轮。
- 确认进度持久保存于既有 learning_state 字段，不升级数据库结构；兼容原有历史数据和 JSON 备份恢复。
- 保存时读取数据库最新进度，不使用过期词卡快照累计次数；更新待复习统计使其包含待确认单词。
- 验证：65 项自动化测试全部通过，静态分析无问题；覆盖本轮循环、三次通过、后续一次通过、遗忘重置、退出恢复与备份恢复。
