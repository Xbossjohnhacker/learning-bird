入口：单词 → 预置词书 → 添加 / 打开词书。空词书页面也有“选择预置词书”入口。词库随安装包提供，无需联网或选择文件。

这是社区开源参考词库，不代表最新版官方完整考试大纲；不承诺收录齐全或释义完全准确。

仅提取单词和中文意思。去除首尾空格，将释义中的转义换行还原；按词形的小写形式去重，保留源文件中首条记录，再按小写字母顺序排序。有效条目需有英文字母和中文释义，单词不超过 120 字符，拒绝词形控制字符与替换乱码。所选分类未发现被这些规则排除的条目。各词书数量与 SHA-256 保存于 `assets/wordbooks/catalog.json`，加载时校验。

## 重新生成

下载上述固定版本 CSV 后运行：

```powershell
python tool/build_builtin_wordbooks.py .artifact_work/ecdict-source/ecdict.csv
```

脚本先核验原始文件哈希，再确定性生成三本 JSON 和目录；更新源版本时必须重新核实分类、来源和许可并更新脚本及测试。三本词书 JSON 合计约 1.3 MiB；原始大 CSV 不打进应用。

## 数据保护与学习

- 只有用户点击添加时才创建词书；不会在启动时自动向用户数据库插入三本书。
- 用稳定的来源标记识别预置词书；重复点击或重新进入只打开已有词书，不补回用户删除的词、不重置进度。
- 自建同名词书不会被覆盖；不同词书共用相同词条时保留已有单词内容及自定义释义，每本书的学习进度独立。
- 添加过程整体入库，任一部分失败都会回滚；页面禁止添加过程中重复提交。
- 新词沿用三次连续认识通过规则；后续复习一次认识通过，遗忘则重新三次。界面不展示认识次数。
- 可照常查看全词表、手动添加、学习及删除整本词书。删除整本词书会删除其进度；之后重新添加视为新书。
- 无数据库结构升级；原有备份格式包含预置标记、词条及进度。

新增资源后，Android Studio 需停止后重新 Run，不能仅依赖热重载。不要卸载应用，以免删除原有数据。
