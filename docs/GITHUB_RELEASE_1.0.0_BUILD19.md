# Learning Bird 1.0.0（Build 19）

这是 Learning Bird 首次 GitHub 公开发布准备版本。

## 本版内容

- 今日计划、周规划、日列表与课程地点展示。
- 多课表创建、选择、切换、删除，并与计划叠加显示。
- Excel 课表导入与教务系统网页课表读取。
- 课程名、节次、周次、教室地点和授课教师解析；冲突课程叠放。
- 单词 Excel/CSV 导入、手动添加、预置考研/四级/六级词书。
- “认识 / 不认识 / 跳过”词卡流程与复习计划。
- 番茄钟、后台通知提醒和本地资料工具箱。
- JSON 数据备份与恢复。

## 安装要求

- Android 8.0（API 26）或更高版本。
- 应用完全离线运行；教务系统网页读取过程需要用户主动打开相应网站。
- 通知、精确闹钟、全屏提醒和后台运行效果受手机厂商系统设置影响，请按应用内引导授权。

## 发布安全

APK 仅在使用项目所有者的正式发布密钥签名、验证证书并计算 SHA-256 后上传。调试签名包不作为公开下载版本。
