# Learning Bird｜把每一天，学得更有方向

计划写了很多，真正完成的却很少？  
背过的单词总在忘，学习资料又散落在不同文件夹？

**Learning Bird** 是一款为考研与长期学习打造的离线学习管理工具。它把计划、背词、番茄专注和本地资料放在一起，让“我今天要做什么”变得清晰，也让每一次完成都能被记录。

![今日总览](../screenshots/01-today.png)

## 像课程表一样安排一周

完整周规划一屏看完，课程与计划可以同时展示。支持导入课程表、显示地点、处理重叠安排，也可以左右滑动查看其他周。

![周规划表](../screenshots/04-week-plan.png)

## 背单词，只保留真正需要的选择

词卡只需要选择“认识”或“不认识”。新词连续认识三次后通过；后续复习认识一次即可，一旦遗忘就自动回到强化学习。应用内置考研、四级、六级词书，也支持 Excel 重复导入和手动添加。

![词书管理](../screenshots/02-word-books.png)

![单词词卡](../screenshots/03-word-card.png)

## 专注与休息，都不会错过

自定义番茄钟的专注和休息时长。阶段结束后，即使你正在桌面或使用其他应用，也能收到通知提醒。

![番茄钟](../screenshots/05-pomodoro.png)

## 还有这些实用能力

- 为每本词书单独设置每日学习量，达标后仍可继续学习
- 导入考研资料文件夹，在应用内查看文本或播放视频
- 按日、周、月查看计划、背词与专注统计
- 核心数据本地保存，支持完整备份与恢复
- Android 8.0 及以上设备可用

**Learning Bird——不是把计划写得更满，而是让每一次学习都有去处。**

当前为 **1.0 候选测试版**，欢迎参与内测并反馈使用体验。测试前建议备份重要学习数据。
